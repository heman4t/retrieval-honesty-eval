# Lantern Roadmap

This roadmap is the only document that schedules Lantern work. Any other plan in this repository is history and schedules nothing.

## Current quarter

The three goals for this quarter are: G1, deliver every accepted webhook at least once; G2, show each delivery attempt in the dashboard; G3, keep the p99 enqueue latency under 50 milliseconds.

## Not in scope

Multi-region failover is not scheduled this quarter.
